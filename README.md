# FF MAX SCOUT

A Flutter starter for a Free Fire MAX squad-finder app.

## Current contents
- Home screen with Find Squad, Create Squad, Find Players and My Profile entry points.
- Placeholder dialogs only; no authentication, cloud database, matchmaking or live squad listings yet.

## Important
This ZIP is a source starter, not a verified APK build. The Android folder is a minimal Gradle project scaffold. For a reliable Android build, open the project in a Flutter development environment and run `flutter create . --platforms=android` from this folder (after backing up), then `flutter pub get` and `flutter build apk`.

Do not upload only `pubspec.yaml`; upload the complete project structure.
